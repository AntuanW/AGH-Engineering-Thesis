# AGH-Engineering-Thesis

University: AGH University of Krakow <br>
Faculty: Computer Science <br>
Authors: Antoni Wójcik, Grzegorz Piśkorski, Zuzanna Olszówka, Bartłomiej Słupik <br>

### Stack
- python
- FastAPI
- MongoDB
- Java
- React

- python 3.12
